# 节奏伴侣

面向家庭运动场景的节奏提示 App，当前使用 Expo SDK 57 + React Native + TypeScript，优先覆盖 Android，也可用同一份代码构建 iPhone 版本。

## 当前首版

- 内置轻松健走、快慢交替、晨间拉伸三个示例计划
- 创建、编辑、复制、删除多个计划
- 每个计划由多个阶段组成，可增删阶段并以分钟/秒设置时长（最短 1 秒）
- 使用真实时间戳计时，减少切后台或设备卡顿造成的误差
- 阶段切换时使用中文语音、触感和屏幕提示
- 没有背景音乐时，训练运行中每秒播放一次轻提示音；语音播报期间自动暂停提示音
- 从手机选择 MP3、WAV 等本地音频作为背景音乐；MIDI 文件会在导入时转换为 WAV
- 每个计划可单独调整、替换或移除背景音乐；语音播报期间音乐自动降低，播报完成后恢复
- 编辑阶段时长使用分钟/秒双列循环滚轮（分钟上限 60 分钟），可上下拖拽选择并带惯性阻尼；Android 返回键按页面层级返回
- 训练音频支持返回手机桌面后继续播放，并提供锁屏控制
- 计划和提醒设置保存在本机，无需账号
- 提供语音、震动和大字体模式

## 启动

```bash
npm install
npm start
```

在 Android 真机或模拟器上运行：

```bash
npm run android
```

在 macOS 上运行 iPhone 模拟器：

```bash
npm run ios
```

也可以使用 Expo Go 扫码预览界面。后台播放、锁屏控制等能力建议使用 development build 验证。

## 下一步建议

首版验证父亲实际使用时，优先测试锁屏、蓝牙耳机、来电打断、省电模式和不同系统音量。后续可增加训练历史、计划导入导出、家人协助配置以及云同步。
